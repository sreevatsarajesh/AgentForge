# Contributing

1. Search existing tools and open an issue describing the use case.
2. Keep each tool focused on one clear job.
3. Add or update its registry entry and Agent Skill.
4. Add tests for deterministic behavior and failure cases.
5. Document inputs, outputs, assumptions and safety boundaries.
6. Run `pytest` before opening a pull request.
7. Do not add network access, shell execution or destructive behavior without explicit design review.

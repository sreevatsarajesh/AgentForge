# Tool Catalogue

## Productivity

- `productivity_meeting_agenda` — Create a focused meeting agenda with objectives, timed topics, preparation and decisions.
- `productivity_meeting_minutes` — Turn supplied notes into decisions, discussion points, owners and follow-ups.
- `productivity_action_items` — Extract tasks, owners, deadlines and unresolved questions from supplied text.
- `productivity_task_prioritizer` — Rank tasks using urgency, impact, effort and dependencies.
- `productivity_weekly_planner` — Turn goals and available hours into a realistic weekly schedule.
- `productivity_personal_budget` — Organize income, expenses, savings targets and cash-flow assumptions.
- `productivity_compound_interest` — Calculate future value from principal, rate, compounding and duration.
- `productivity_loan_calculator` — Estimate installment, total interest and repayment schedule.
- `productivity_expense_categorizer` — Categorize supplied expense descriptions using transparent keyword rules.
- `productivity_meal_planner` — Create a flexible meal plan from preferences, budget and available ingredients.

## Writing

- `writing_blog_outline` — Create a structured article outline with audience, angle and section goals.
- `writing_article_brief` — Prepare a writer brief with thesis, audience, evidence needs and structure.
- `writing_social_post` — Draft platform-aware social content from a supplied message.
- `writing_press_release` — Structure a factual press release with headline, lead, details and boilerplate.
- `writing_faq_generator` — Turn supplied product or policy information into clear question-and-answer pairs.
- `writing_plain_language` — Simplify dense text while preserving important qualifications.
- `writing_proofreading` — Identify grammar, spelling, clarity and consistency issues in supplied text.
- `writing_resume_bullets` — Convert work or project descriptions into achievement-focused resume bullets.
- `writing_cover_letter` — Create a tailored cover letter draft from a role and candidate evidence.
- `writing_speech_outline` — Build a speech structure with opening, key points, transitions and close.

## Learning

- `learning_concept_explainer` — Explain a topic at a selected level with examples and misconceptions.
- `learning_flashcard_generator` — Create concise question-and-answer flashcards from supplied learning material.
- `learning_quiz_generator` — Generate a quiz with answer key and explanations from supplied material.
- `learning_study_plan` — Build a study schedule from topics, available time and target date.
- `learning_lesson_plan` — Create learning objectives, activities, materials and assessment.
- `learning_rubric_builder` — Create criteria and performance levels for an assessment.
- `learning_glossary_builder` — Extract or define key terms in a supplied subject area.
- `learning_reading_guide` — Create guiding questions, vocabulary and reflection prompts for a text.
- `learning_practice_questions` — Create varied practice questions with worked answer guidance.
- `learning_spaced_repetition` — Schedule review sessions using an adjustable recall-based interval plan.

## Data

- `data_csv_profiler` — Summarize columns, types, missing values and sample records from CSV text.
- `data_csv_filter` — Filter CSV rows by an exact column value.
- `data_csv_aggregate` — Group CSV rows and calculate count, sum or average for a numeric column.
- `data_csv_to_json` — Convert supplied CSV text into JSON records.
- `data_json_validator` — Parse JSON and report validity, structure and top-level keys.
- `data_json_to_csv` — Convert a JSON array of objects into CSV text.
- `data_deduplicate_rows` — Remove duplicate CSV rows and report counts.
- `data_normalize_headers` — Normalize CSV headers to lowercase snake_case.
- `data_text_to_csv` — Format supplied delimited or line-based records as CSV.
- `data_statistics_summary` — Calculate descriptive statistics for a supplied numeric list.

## Business

- `business_swot_analysis` — Build a clearly separated strengths, weaknesses, opportunities and threats analysis.
- `business_competitor_matrix` — Compare supplied competitors against consistent dimensions.
- `business_customer_persona` — Create an evidence-labelled customer persona from supplied research.
- `business_value_proposition` — Clarify audience, problem, outcome and differentiator.
- `business_business_model_canvas` — Draft the nine building blocks of a business model.
- `business_pricing_calculator` — Calculate unit economics, markup, margin and suggested price from inputs.
- `business_break_even_calculator` — Calculate break-even units and revenue from fixed costs and contribution margin.
- `business_budget_builder` — Organize income, costs, assumptions and variance tracking.
- `business_kpi_tree` — Translate a business objective into drivers and measurable indicators.
- `business_risk_register` — Create a risk register with likelihood, impact, mitigation and owner.

## Coding

- `coding_code_explainer` — Explain supplied source code, its flow, assumptions and edge cases.
- `coding_python_ast_summary` — Parse Python source and list imports, functions, classes and syntax errors.
- `coding_regex_tester` — Test a regular expression against supplied sample text.
- `coding_dependency_inventory` — Extract likely imports and dependencies from supplied source text.
- `coding_changelog_generator` — Turn supplied commits or changes into categorized release notes.
- `coding_commit_message` — Create concise conventional commit message suggestions from a change summary.
- `coding_test_case_designer` — Design positive, negative, boundary and regression test cases.
- `coding_api_spec_drafter` — Draft endpoint contracts with methods, inputs, outputs and error cases.
- `coding_sql_query_helper` — Translate a described data question into a parameterized SQL draft.
- `coding_config_validator` — Parse and validate JSON or TOML configuration and report structural issues.

## Research

- `research_research_brief` — Define a research question, scope, method, evidence needs and deliverables.
- `research_evidence_matrix` — Organize supplied sources or excerpts by claim, evidence, limitations and relevance.
- `research_claim_evidence_review` — Assess whether supplied evidence supports a claim without inventing external verification.
- `research_literature_synthesis` — Synthesize supplied study summaries by themes, agreements and gaps.
- `research_citation_formatter` — Format bibliographic details into a selected citation style.
- `research_interview_guide` — Create neutral interview questions, probes and consent reminders.
- `research_survey_builder` — Create unbiased survey questions and response options for a defined objective.
- `research_qualitative_coder` — Suggest themes and codes for supplied qualitative excerpts.
- `research_source_comparison` — Compare supplied sources by method, evidence, scope and limitations.
- `research_research_questions` — Develop focused, feasible and researchable questions from a topic.

## Career

- `career_resume_review` — Review supplied resume text for clarity, relevance, evidence and consistency.
- `career_job_match` — Compare supplied experience against a job description and identify evidence gaps.
- `career_interview_practice` — Generate role-specific interview questions and evaluation guidance.
- `career_star_story_builder` — Structure an experience into situation, task, action and result.
- `career_networking_message` — Draft concise, respectful networking outreach for a specific context.
- `career_salary_negotiation` — Prepare a negotiation case, questions and respectful response scripts.
- `career_career_roadmap` — Create staged career goals, skills, projects and checkpoints.
- `career_skill_gap_analysis` — Compare target-role skills with current evidence and prioritize learning.
- `career_portfolio_project` — Design a portfolio project with scope, milestones and demonstrable outcomes.
- `career_performance_review` — Organize accomplishments, impact, learning and next-period goals.

## Creative

- `creative_slogan_generator` — Create concise slogan options for a supplied brand or campaign.

- `creative_presentation_outline` — Create a slide-by-slide narrative with key messages and evidence needs.

- `operations_process_map` — Represent a workflow as ordered steps, decisions, inputs and outputs.
- `operations_raci_matrix` — Assign responsible, accountable, consulted and informed roles.
- `operations_project_charter` — Define project purpose, scope, stakeholders, outcomes and constraints.

- `operations_retrospective` — Structure what went well, what did not, insights and experiments.
- `operations_incident_report` — Organize incident facts, impact, timeline, response and follow-up.
- `operations_change_request` — Document a proposed change, rationale, impact and approval path.
- `operations_event_plan` — Plan objectives, schedule, roles, logistics, communications and contingencies.
- `operations_procurement_checklist` — Create requirements, vendor evaluation, due diligence and acceptance checks.
